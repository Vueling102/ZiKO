# ZiKO
ZiKO, rhythm is just a *green flag* away!

ZiKO is a rhythm game scratch project inspired by osu!  (all rights 
reserved to its creators).
 
Here in ZiKO we don't want to make a perfect copy of osu!, instead, 
we want to:
 
- Recreate the menu and gameplay of osu! as a challenge.
- Show what we can build
- Last but not least, try to make it a little different to add our own 
options and little touches
 
ZiKO is made by fans, but for fans, with love for osu! and the desire to 
create something of our own.
